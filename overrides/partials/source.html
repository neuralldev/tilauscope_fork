{#- Material's stock `partials/source.html`, with one attribute removed. The stock partial carries `data-md-component="source"`, and that attribute is what makes the theme's bundle fetch https://api.github.com/repos// on every page load, to print a star and fork count next to the repository name. Two reasons that is not wanted here: 1. It is a third-party request on every page a reader opens. The rest of tilauscope.org is built so that no such request exists — that is what lets its Content-Security-Policy be written without an escape hatch — and the documentation should not be the one place that quietly breaks the rule. 2. api.github.com rate-limits unauthenticated callers by IP, so the counts are unreliable anyway. Everything else is untouched: the repository link and its icon still render. Removing the attribute is the whole change; keep it that way, so that a Material upgrade that reworks this partial is easy to re-apply. -#}
